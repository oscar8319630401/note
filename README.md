# 📒 나의 복습 노트

**초등 고학년을 위한 복습 공책** — 쓰고, 복습하고, 기억 나무를 키워요 🌱

👉 **[https://oscar8319630401.github.io/note/](https://oscar8319630401.github.io/note/)**

국어·수학·사회·과학·영어를 복습하며 적는 노트입니다. 학습과학에서 검증된 두 가지 —
**스스로 문제 내기(액티브 리콜)**와 **간격 반복(장기기억)** — 을 재미있게 담았습니다.

## 복습 노트 한 장 (코넬식)

제목 · 핵심 내용(내 말로) · ⭐ 꼭 기억할 것 · ✏️ 내가 만든 문제+답 · ❓ 어려웠던 것 · 이해도

- 노트마다 **날짜가 자동으로 찍혀** 저장됩니다 (한 학기 분량도 문제없어요)

## 기능

- **🌱 기억 나무** — 정해진 날(1→3→7→14→30일) 복습할 때마다 씨앗→새싹→잎→나무→열매→⭐완전 내 것! 으로 자라요. 재미이자 장기기억 장치(간격 반복)
- **🧠 내 문제로 퀴즈** — 내가 적은 문제가 퀴즈로! 스스로 답을 맞혀요
- **📣 오늘의 영어 5문장** — 생활회화·명언·속담이 매일 바뀌고, 🔊로 발음도 들려줘요
- **⏱️ 공부 타이머** — 복습한 시간을 재고 오늘·이번 주 누적을 봐요
- **🏆 성취** — 스티커·배지·연속 기록으로 스스로를 칭찬해요
- **🎤 음성 입력** — 타이핑 대신 말로 정리
- **🖨️ 인쇄 / 🗑️ 삭제** — 노트를 종이로 뽑거나, 마음에 안 들면 지우고 다시 쓰기

모바일·PC 지원. 모든 기록은 이 기기(브라우저)에만 저장돼요.

## 개발

```bash
npm install
npm run dev        # http://localhost:5175
npm run build
npm run typecheck
```

`main`에 push하면 GitHub Actions가 빌드해 Pages에 배포합니다.

## 기술 스택

React 18 · TypeScript · Vite · zustand · Web Speech API(음성 인식·읽어주기)
